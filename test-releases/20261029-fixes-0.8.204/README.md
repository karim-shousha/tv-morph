# Morph TV 0.8.204 review

Install the matching TV or phone APK over the previous matching app. No public update feed was changed.

- M3U import now streams rows and supports larger lists, bounded at 96 MiB of text / 100000 entries; no silent partial import. The submitted subscription itself was not accessed or tested.
- Exit the root application with two Back presses within two seconds, with no message. Back within folders/pages still returns one step.
- OEM inputs with custom HDMI labels/generic passthrough are preserved even if state access is denied. If direct HDMI is not exposed, open the real TV source-selector card; system settings is the last fallback. Physical Mega TV behavior is not yet verified and universal individual-port support is not claimed.
- DLNA / Local Network text is visible below the sidebar icon.
- Folders use the same glass dock style with colored symbols rather than solid colored backgrounds.

All automated test results and unverified physical-device limitations are recorded in manifest.json. APK signatures and published download hashes are checked.
