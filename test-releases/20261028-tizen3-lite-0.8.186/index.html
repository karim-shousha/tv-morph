EXPERIMENTAL · SAMSUNG 2017 · TIZEN 3.0

Morph TV Lite 3 · 0.8.186

نسخة خفيفة تجريبية لأجهزة سامسونج القديمة مثل UA50MU7000. خلفية ثابتة، بدون بلور أو ظلال أو حركة مستمرة، وتحديد واضح للريموت.

قبل التحميل

دي نسخة توافق مرشحة للتجربة، وليست دعمًا مؤكدًا للجهاز. ملفات JavaScript اتراجعت بصيغة ES5 والواجهة اتجربت مع بدائل التوافق. لم يتم اختبار تلفزيون Tizen 3 فعلي أو تشغيل محرك Chromium 47.

اسمها Morph TV Lite 3 ولها هوية مستقلة؛ لا تستبدل التطبيق الحالي. لا تمسح النسخة الأصلية.

حزمة الكمبيوتر · ZIP · حوالي 7 ميجاحزمة WGT موقعة للتجربة

التثبيت بالكمبيوتر

  1. ثبّت Tizen Studio وإضافتي TV وSamsung Certificate.
  2. فعّل Developer Mode من Apps باستخدام 12345، واكتب IP الكمبيوتر في Host PC IP، ثم أعد تشغيل التلفزيون.
  3. اربط الجهاز في Device Manager على المنفذ 26101، وأضف DUID التلفزيون لشهادة الموزّع.
  4. فك حزمة الكمبيوتر وشغّل السكربت باسم شهادة سامسونج الخاصة بك:
./Install-Tizen3.ps1 -TVIP 192.168.1.2 -CertificateProfile MySamsungProfile

ملف WGT الموقّع لن يثبت لو DUID جهازك مش موجود في شهادته؛ استخدم حزمة الكمبيوتر لإعادة التوقيع بشهادتك. لا توجد مفاتيح خاصة داخل التحميلات.

ليست APK أو مثبت فلاشة. مثبت الموبايل الحالي يحتوي نسخة سامسونج العادية؛ لا تستخدمه لتجربة Lite 3.

نجرب إيه؟

فتح الهوم، الريموت، التطبيقات، تغيير الثيم، ثم إضافة اشتراك M3U أو Xtream وتجربة قناة H.264/AAC. جرّب كيدزي بصورة وصوت وHDMI مع جهاز متصل.

المشاهدة المتعددة وPortal/MAC غير مدعومين على سامسونج. توافق القنوات وTLS وشهادة التثبيت يعتمد على الجهاز؛ ابعت رسالة الخطأ وصورة الموديل لو ظهر عطل.
