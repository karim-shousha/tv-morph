# Morph TV 0.8.205 review

Install the matching TV or phone APK. Re-enter the same complete provider get.php link in the M3U account form and press Connect & save. For compatible Xtream providers the app now uses player_api.php authentication and separate catalogs, avoiding the enormous full playlist. Generic/public M3U behavior is preserved. If provider API auth fails, the original playlist is attempted; large generic lists remain bounded, not silently truncated.

The actual submitted subscription was not accessed during tests. Tests used synthetic credentials and mock auth outcomes. No public update feed or website download center changed. DLNA sidebar name is now DLNA only. Includes prior review changes.
