# Morph TV 0.8.203 — Dock folders review

Android TV: install Morph-TV-Dock-Folders-0.8.203-review.apk over the matching existing Android TV app.
Phone companion: install Morph-Mobile-Dock-Folders-0.8.203-review.apk over the matching mobile app.

Home dock → New folder → enter name → Save. Each new folder gets an automatic color. Long-press an app → Move to folder → choose folder. Open the folder to show its apps in the same dock. Back returns to the main dock. Inside the folder, its settings button provides rename/delete; deleting restores apps to the main dock. Move to Main dock moves a single app out. Folder organization is separate per family profile.

This is an isolated review build, not a public update. Includes Local Network implementation from the current review branch; no compatible hardware was available for physical verification. Native playback/device discovery are not claimed device-tested. No Samsung WGT or LG IPK in this release.
