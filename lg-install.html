تنزيل ملف LG

زر تنزيل LG يحفظ ملف IPK فقط. متصفح التلفزيون والفلاشة لا يثبّتان الملف تلقائيًا. للتثبيت من الموبايل استخدم تطبيق Morph TV أو webOS Dev Manager بالخطوات أدناه. الكمبيوتر له طريقة مستقلة موضحة كذلك. لا يلزم نقل الملف يدويًا من الموبايل إلى التلفزيون عند استخدام زر التثبيت في تطبيقنا.

الطريقة الأولى: التثبيت من تطبيق Morph TV للموبايل

  1. جهّز الشاشة والموبايل

    وصّل شاشة LG وموبايل Android بنفس الراوتر. افتح متجر التطبيقات على الشاشة وابحث عن Developer Mode.

    Developer Mode برنامج على التلفزيون. تطبيق Morph TV للموبايل برنامج مختلف.

  2. سجّل دخولك على الشاشة

    افتح Developer Mode على LG وسجّل بحساب LG Developer. لو معندكش حساب، اعمله من موقع LG الرسمي الأول.

    ما تكتبش كلمة سر حساب LG في تطبيق الموبايل.

  3. فعّل وضع المطوّر

    شغّل Dev Mode Status ووافق على إعادة التشغيل. بعد ما الشاشة تفتح، افتح Developer Mode تاني وشغّل Key Server.

    دي خطوة تجهيز؛ لسه Morph TV ما اتثبتش على الشاشة.

  4. خد بيانات الشاشة

    سيب Developer Mode ظاهر واقرأ IP Address وPassphrase. اكتب IP من الشمال لليمين زي 192.168.1.25.

    استخدم IP التلفزيون، مش الموبايل. احتفظ بالـPassphrase لنفسك.

  5. ثبّت Morph TV من الموبايل

    افتح Morph TV على Android، اختار التلفزيون ثم LG webOS، واكتب IP الشاشة. اضغط تثبيت LG، واكتب Passphrase الظاهر على الشاشة وأكد بصمة الجهاز.

    استنى رسالة نجاح التثبيت. تطبيقنا بينقل ملف LG للتلفزيون؛ مش محتاج مدير webOS إضافي.

  6. افتحه على الشاشة واربط

    من تطبيقات LG افتح Morph TV بالريموت. ارجع للموبايل واضغط اتصال. بعد تأكيد الربط تقدر تغير الثيم وتضيف اشتراك IPTV الخاص بيك.

    لو التطبيق موجود بالفعل، استخدم ربط LG بالمفتاح · بدون إعادة تثبيت.

  7. التحديث وتجديد المدة

    للتحديث افتح أحدث Morph TV على الموبايل واضغط تثبيت LG مرة تانية. افتح Developer Mode دوريًا وجدد المدة بزر EXTEND قبل انتهائها.

    زر Home بيرجع لواجهة LG. ملف APK للموبايل؛ ملف IPK للشاشة. Morph TV لا يوفّر قنوات.

ببساطة: Developer Mode على شاشة LG ← Morph TV على موبايل Android ← ربط الشاشة بالموبايل ← تثبيت Morph TV على الشاشة.

الطريقة الثانية: من موبايل Android باستخدام webOS Dev Manager

دي نفس الطريقة المقترحة في الرسالة. اسم الأداة الصحيح webOS Dev Manager من webOSbrew؛ أداة مستقلة عن Morph TV وعن تطبيق Developer Mode الموجود على الشاشة. اختار الطريقة دي أو التثبيت من تطبيق Morph TV؛ مش لازم تعمل الاتنين.

تنزيل webOS Dev Manager من Google Playتنزيل ملف Morph TV · IPK
  1. على شاشة LG: افتح متجر LG Apps / Content Store، وابحث عن Developer Mode وثبّته. افتحه وسجّل بحساب LG Developer. يمكنك إنشاء الحساب من موقع LG الرسمي.
  2. فعّل Dev Mode Status ووافق على إعادة التشغيل. بعد تشغيل الشاشة افتح Developer Mode مرة تانية وفعّل Key Server.
  3. على الموبايل: وصّله بنفس شبكة Wi-Fi الخاصة بالشاشة، وافتح webOS Dev Manager. اختار إضافة جهاز، واكتب IP Address وPassphrase الظاهرين داخل Developer Mode على التلفزيون. لو طلب المنفذ استخدم 9922 والمستخدم prisoner. أكّد بصمة الشاشة بعد التأكد من عنوانها. أسماء الأزرار قد تختلف حسب لغة وإصدار الأداة.
  4. نزّل ملف Morph TV بصيغة IPK من الزر بالأعلى على الموبايل. داخل مدير webOS اختار تثبيت ملف محلي / Install IPK، وحدّد الملف من مجلد التنزيلات. اختيار Morph TV من متجر الأداة ليس مطلوبًا؛ استخدم الملف الذي نزّلته من موقعنا.
  5. انتظر نجاح التثبيت، ثم افتح Morph TV من قائمة تطبيقات شاشة LG بالريموت. لتغيير الثيم والتحكم من الهاتف، افتح تطبيق Morph TV للموبايل واربطه بالتلفزيون؛ مدير webOS أداة تثبيت فقط.
  6. قبل انتهاء Remaining Session افتح Developer Mode واضغط EXTEND مع اتصال الإنترنت. لو انتهت الجلسة وتعطّل وضع المطوّر فقد تُحذف تطبيقات التطوير وتحتاج تثبيتها من جديد.

مهم: ملف LG هو IPK، وليس APK. هذه الطريقة لا تحتاج روت، ولا تجعل التطبيق متاحًا في متجر LG الرسمي. لا يلزم تثبيت YouTube أو أي تطبيق إضافي لاستخدام Morph TV.

لو الاتصال أو التثبيت مش بيكمل

  • تأكد أن Key Server شغال وأن Developer Mode لم تنتهِ مدته. استخدم IP الحالي للشاشة؛ قد يتغير بعد إعادة التشغيل.
  • خلي الجهازين على نفس الشبكة، وأوقف VPN مؤقتًا، وتجنب شبكة الضيوف أو عزل الأجهزة في الراوتر. لا تفتح منافذ الراوتر على الإنترنت.
  • أعد إدخال Passphrase الموجود حاليًا على الشاشة. لا ترسل كلمة سر حساب LG أو Passphrase لأي شخص.
  • لو الموبايل آيفون أو الأداة غير متاحة عندك، استخدم طريقة الكمبيوتر التالية. لو Developer Mode غير موجود بمتجر شاشتك، ابعت لنا الموديل وإصدار webOS على support@herroshetta.com.

الحزمة الحالية تستهدف webOS 5.0 فأحدث، ولا تناسب NetCast. شرح طريقة التثبيت لا يعني تأكيد التوافق على كل موديل؛ لم نختبر الحزمة على شاشة LG فعلية بعد.

معاك آيفون؟ ثبّت من الكمبيوتر بواجهة سهلة

  1. نفّذ تجهيز Developer Mode وKey Server على الشاشة كما سبق. وصّل الكمبيوتر والشاشة بنفس الراوتر.
  2. نزّل webOS Dev Manager للكمبيوتر من صفحة المشروع بالإصدار المناسب لنظامك، وافتحه.
  3. أضف الشاشة باستخدام IP وPassphrase الظاهرين عليها، ثم نزّل ملف Morph TV بصيغة IPK على الكمبيوتر.
  4. اختار Install وحدد ملف IPK، وانتظر النجاح ثم افتح Morph TV من الشاشة. لا تحتاج موبايل Android. الفلاشة لن تثبّت IPK بمجرد الضغط عليه.

الاستخدام والتطبيقات

غيّر الثيم والإعدادات والمفضلة من الموبايل، وتحكم بالأسهم وOK وBack داخل Morph TV، واربط IPTV الخاص بك. التطبيق يجب أن يكون مفتوحًا وDeveloper Mode فعالًا. الصوت وباقي واجهة LG من الريموت الأصلي. اختصار HDMI وقنوات التلفزيون داخل Morph TV يفتح المصدر في مشغّل LG عند سماح النظام؛ لو رفض الجهاز استخدم زر Input أو Live TV في الريموت الأصلي.

قبل المزامنة، «إضافة تطبيق» يبدأ بتطبيقات معروفة مثل شاهد وNetflix وYouTube وPrime Video وDisney+، ويظهر المثبت منها فقط. لعرض باقي التطبيقات المرئية: حدّث نسختي الموبايل وLG إلى 0.8.136، افتح Morph TV على الشاشة، ثم وصّل الريموت أو اضغط تحديث التطبيقات من الموبايل. لا تشمل المزامنة بالضرورة تطبيقات النظام المخفية. فتح تطبيق خارجي يعتمد على سماح LG؛ عند الرفض يظهر الخطأ بدون محاولة تثبيت أو تجاوز القيود.

الراديو يواصل التشغيل عند الرجوع للهوم داخل Morph TV، مع زر إيقاف. يتوقف عند تشغيل فيديو أو الأذان أو الخروج من التطبيق. تشغيل الوسائط يعتمد على ترميز الشاشة واتصال المزوّد. بيانات IPTV محفوظة محليًا داخل التطبيق ويمكن مسحها من IPTV Settings. لا يتضمن التطبيق قنوات أو اشتراكات.

الحدود والرجوع

التثبيت هنا عبر Developer Mode وليس عبر LG Store. لا تستبدل LG Home ولا تعيد تعيين زر Home ولا تضمن التشغيل التلقائي. راجع Remaining Session / Extend في Developer Mode؛ انتهاء الجلسة ثم إعادة التشغيل قد يحذف تطبيقات التطوير.

  1. اضغط Home للرجوع لواجهة LG.
  2. اضغط «إلغاء ربط LG ومسح المفتاح» من الموبايل لمسح بيانات الاتصال المحلية.
  3. لحذف التطبيق، احذف Morph TV من تطبيقات الشاشة. إلغاء الربط وحده لا يحذفه.
التثبيت من الكمبيوتر · اختياري للمستخدم المتقدم

بعد تثبيت Node.js استخدم CLI الرسمي:

npm install -g @webos-tools/cli
ares-setup-device
ares-novacom --device morph-lg --getkey
ares-install --device morph-lg Morph-TV-LG-0.8.136.ipk

ares-install --device morph-lg --remove com.zainbot.morphtv.preview

الفرق بين المنافذ والتطبيقات

منفذ اتصال Developer Mode هو 9922. منفذ 9991 مخصص لتنزيل المفتاح من Key Server؛ لا تستبدل أحدهما بالآخر. لو البحث التلقائي لم يجد الشاشة، أدخل IP التلفزيون يدويًا بعد توصيل الجهازين بنفس الراوتر.

في تحديث 0.8.136: حدّث تطبيق الموبايل ونسخة LG معًا، وافتح Morph TV على الشاشة. وصّل الريموت من الموبايل أو اضغط تحديث التطبيقات لجلب التطبيقات المرئية التي يسمح LG بعرضها، ثم اختر التطبيقات لإضافتها إلى Home. يتم التأكد من وجود كل تطبيق قبل فتحه. بعض تطبيقات النظام قد لا تظهر. البحث الأولي لا يستطيع عرض كل التطبيقات بدون مزامنة Developer Mode. اختصار HDMI وقنوات التلفزيون يفتح مشغّل LG إذا سمح النظام؛ لا يتم ادعاء اكتشاف حالة الكابل أو تقديم دليل قنوات داخل Morph TV.

Morph TV لا يستبدل زر Home الخاص بنظام LG. تشغيل الأذان يتطلب بقاء التطبيق ظاهرًا؛ webOS قد يعلّق أو ينهي التطبيق في الخلفية.
