سامسونج: تنزيل WGT وتثبيته من الكمبيوتر

اختار إصدار نظام تلفزيونك. تنزيلات الكمبيوتر WGT فقط. فك الملف وإعادة توقيعه بشهادتك مطلوبان؛ تغيير الامتداد وحده لا يكفي. تثبيت الموبايل لم يتغير.

Tizen 3 و4 تجريبيان. نجاح Lite 3 على Tizen 5 لا يثبت توافق كل أجهزة Tizen 3.

Tizen 2.3 / 2.4 Lite · 0.8.217

تنزيل Tizen 2 Lite · WGT للكمبيوتر

نسخة خفيفة تجريبية للأجهزة القديمة. تحتاج توقيعًا بشهادة تشمل DUID التلفزيون؛ التوافق يختلف حسب الموديل. ابدأ بالأمرين التاليين، ثم أكمل خطوات الشهادة والتوقيع أدناه:

$sourceWgt = Join-Path $env:USERPROFILE "Downloads\Morph-TV-Tizen2-Lite-0.8.217-candidate.wgt"
$packageId = "MorphT2001"

Tizen 5+ · 0.8.244

تنزيل WGT للكمبيوتر

بعد التحميل، ابدأ بالأمر الخاص بهذه النسخة:

$sourceWgt = Join-Path $env:USERPROFILE "Downloads\Morph-TV-Samsung-Tizen5-0.8.244.wgt"
$packageId = "ClearMob01"

الشهادة والسماح بالتثبيت

Certificate Manager → Samsung → TV. أنشئ Profile وAuthor Certificate، ثم Distributor Certificate بصلاحية Public، وأضف DUID التلفزيون. احتفظ بالشهادة وكلمة مرورها للتحديثات. في Device Manager اضغط كليك يمين على التلفزيون → Permit to install applications.

فك WGT وإعادة توقيعه

نفّذ أولًا أمر النسخة المختارة أعلاه، ثم الأوامر التالية في نفس نافذة PowerShell. عدّل عنوان التلفزيون واسم شهادة MorphTV حسب جهازك. مصدر الملفات ومجلد الملف الموقّع منفصلان تلقائيًا.

$tvAddress = "10.0.0.153:26101"
$certificateProfile = "MorphTV"
$workRoot = Join-Path $env:USERPROFILE ("Downloads\Morph-Sign-" + [guid]::NewGuid().ToString("N"))
$sourceFolder = Join-Path $workRoot "source"
$outputFolder = Join-Path $workRoot "signed"
New-Item -ItemType Directory -Path $outputFolder -Force | Out-Null
Add-Type -AssemblyName System.IO.Compression.FileSystem
[System.IO.Compression.ZipFile]::ExtractToDirectory($sourceWgt, $sourceFolder)
& "C:\tizen-studio\tools\ide\bin\tizen.bat" package -t wgt -s $certificateProfile -o $outputFolder -- $sourceFolder

لا تكمل إلا بعد نجاح التوقيع وظهور ملف WGT في مجلد signed.

التثبيت والتشغيل

سيب التلفزيون شغال، واقفل Device Manager، ثم نفّذ:

$signedWgt = Get-ChildItem -LiteralPath $outputFolder -Filter *.wgt
if (@($signedWgt).Count -ne 1) { throw "Expected one signed WGT. Check the signing output." }
$remoteWgt = "/home/owner/share/tmp/sdk_tools/morph-" + [guid]::NewGuid().ToString("N") + ".wgt"
& "C:\tizen-studio\tools\sdb.exe" connect $tvAddress
& "C:\tizen-studio\tools\sdb.exe" -s $tvAddress push $signedWgt.FullName $remoteWgt
& "C:\tizen-studio\tools\sdb.exe" -s $tvAddress shell 0 vd_appinstall $packageId $remoteWgt

استنى install completed. cmd_ret:0 وحده لا يكفي. لو ظهر فشل توقّف واحتفظ بالناتج. الحذف ليس مطلوبًا للتحديث المعتاد وقد يمسح الإعدادات والتفعيل.

بعد نجاح التثبيت افتح التطبيق من Apps، أو نفّذ:

& "C:\tizen-studio\tools\sdb.exe" -s $tvAddress shell 0 execute ($packageId + ".Home")
