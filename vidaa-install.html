TV Morph على VIDAA

نسخة ويب تجريبية مستقلة · 0.1.0

  1. من التلفزيون افتح تطبيق Browser / Internet.
  2. في شريط العنوان أعلى المتصفح اكتب:hisense://debug
  3. إذا ظهرت صفحة التثبيت، املأ البيانات التالية:

    App Name

    TV Morph

    App Url

    https://tvmorph.zainbot.com/vidaa.html

    Thumbnail (اختياري)

    https://tvmorph.zainbot.com/tvmorph.png

    Resolution: اختار 1080.

  4. اضغط Install ثم ارجع لقائمة تطبيقات الشاشة وابحث عن TV Morph. فتح صفحة الويب وحده لا يؤكد التثبيت.

لو صفحة التطوير لا تفتح، جرّب زر فتح النسخة بالمتصفح أدناه لاختبار التشغيل. هذه ليست طريقة تثبيت بديلة. إتاحة صفحة التطوير تختلف حسب إصدار الشاشة؛ النسخة لم تُختبر بعد على جهاز VIDAA فعلي.

فتح النسخة للتجربة في المتصفح

المتاح: الثيمات والعربية والإنجليزية ومكتبة روابط فيديو وراديو مباشرة. ربط الموبايل، HDMI، تطبيقات النظام واستيراد حسابات IPTV لم تُضف بعد.

TV Morph on VIDAA

Dedicated hosted web development build · 0.1.0

  1. On your television, open Browser / Internet.
  2. Enter this in the browser address bar:hisense://debug
  3. If the developer install page opens, enter:

    App Name

    TV Morph

    App Url

    https://tvmorph.zainbot.com/vidaa.html

    Thumbnail (optional)

    https://tvmorph.zainbot.com/tvmorph.png

    Resolution: 1080.

  4. Select Install, return to TV Apps and look for TV Morph. Opening the web page alone does not confirm installation.

The development page may be unavailable on your firmware. The button below tests the app in the browser only; it is not an alternative installation method. Physical VIDAA testing is still required.

Test the app in the browser

Includes themes, Arabic/English and a direct video/radio link library. Phone pairing, HDMI, system app controls and IPTV account imports are not included yet.
