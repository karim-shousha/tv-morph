# Morph TV 0.8.242

- Episode lists fill the remaining detail dialog height; seasons share a compact toolbar without a redundant Episodes heading.
- Complete movie/series text is accessible in one focusable scroll area, preserving visible playback actions.
- Continue Watching shows all unfinished movies and episodes in Home and section lists, filters completed playback, and refreshes after playback returns.
- Series Continue Watching resumes its latest unfinished episode. Episodes automatically advance through provider order and stop at the final episode; LG completion now uses the same path as Android and Samsung.
- Browser tests cover both languages, 1080p/720p detail geometry, all-history lists, completion removal, resume selection and next episode across pages/seasons. Physical device validation remains pending.
