# Morph TV 0.8.217

- Official transparent wordmark on IPTV, phone and TV Home. Larger Home logo and compact continuous Home header.
- Text-only IPTV navigation. Readable dark search focus; content type and release year use separate colors.
- Four bundled cinematic backgrounds rotate every 20 seconds, including while browsing cards. No enlarged provider posters or continuous full-screen animation. Pauses outside Home and while hidden/loading.
- Downloaded themes category updates immediately, supports selecting packs and persists via existing IndexedDB. Visible focus restoration and Choose theme action.
- Automated tests cover actual fixture pack download, offline reload, removal, Home/Live navigation, Arabic/English and 720p/1080p layouts.
- Physical TV playback and LG HDMI audio are not verified/fixed by this release. Tizen 2 remains the separate experimental Lite 0.8.215.
